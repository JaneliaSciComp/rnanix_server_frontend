Run RNAnix from Claude

RNAnix exposes a remote MCP (Model Context Protocol) server, so you can fold an RNA/protein complex directly from a Claude conversation instead of the web app — Claude submits the job and reads the result back through the same backend this site uses.

You need an invite first. This connector uses the same invite-only sign-in as the website — if you don't already have RNAnix credentials, ask whoever administers this site to invite your email before continuing.

Option A — Claude Code (CLI)

Add the server, then run claude and log in when your browser opens:

claude mcp add --transport http rnanix <mcp-url>

Option B — claude.ai / Claude Desktop

  1. Open Customize → Connectors (Team/Enterprise: an owner adds this once under Organization Settings → Connectors before members can connect individually).

What it can do today

  • Fold complexes of RNA, protein, DNA, and ligand chains together, from raw sequences.
  • Pick how many seeds / samples to run.
  • Returns the top-ranked structure as raw PDB/mmCIF text once the fold finishes.

Not in this first version: MSA and template selection. Every MCP fold runs single-sequence, template-free, on RNAnix's default model — the same options the chat app's "Expert mode" exposes aren't available here yet.

Custom connectors run from Anthropic's cloud, not your device — so this only requires your RNAnix login, nothing installed locally. Free Claude accounts can add one custom connector; Pro/Max/Team/Enterprise have no such limit.
